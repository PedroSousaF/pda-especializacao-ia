# meu-primeiro-mcp

Esqueleto do LAB 2 (aula 7). Uma tool pronta (`rolar_dado`) e um espaço marcado com
`TODO` pra sua segunda tool.

```bash
npm install
npm test
claude mcp add meu-mcp -- node "$(pwd)/espiao.mjs"     # PowerShell: "$PWD\espiao.mjs"
claude                                                 # na mesma pasta
```

Dentro do Claude Code: `/mcp` pra ver o server, e "rola um d20 pra mim" pra usar.
A conversa entre os dois fica gravada em `conversa.log`.

Passo a passo completo e tabela de erros comuns: `GUIA-DO-ALUNO.md` da pasta
`aula7-mcp-server`.
